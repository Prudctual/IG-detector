Documentation

Welcome to the official technical guide for the Speed Test Forensic Suite. This platform is engineered for high-precision metadata collection and network diagnostic research.

Stealth Capture Silent collection of device fingerprints and network identifiers.
Sensor Fusion High-accuracy GPS tracking combined with ISP geolocation.
Secure Access Role-based access control with session-aware cookie management.

Local Installation

To run the diagnostic workspace on your local machine, ensure you have Node.js (v18 or higher) installed.

# Install dependencies
npm install

# Start the environment
node server.js

Forensic Capabilities

The suite employs advanced attribution techniques to identify visitors beyond simple IP addresses:

  • WebRTC Leak: Bypasses standard VPN tunnels to resolve local network interfaces.
  • Hardware Hash: Combines GPU cores, Audio context, and Canvas rendering to create a unique deviceId.
  • Network Persistence: Tracks visit frequency and session history for each identified device.

Security & Authentication

The dashboard is protected by an industrial-grade authentication layer. You can configure the credentials via environment variables:

ADMIN_USER=Jassim99x
ADMIN_PASS=Jassim99x
Important: The session is maintained via httpOnly cookies to prevent XSS-based credential theft. Always ensure your deployment uses HTTPS in production.

Cloud Deployment

This project is optimized for Vercel and Render. The persistence layer uses JSONBlob, allowing the application to remain stateless while maintaining a consistent database across distributed nodes.

Legal & Ethical Usage

This software is provided for authorized security research and diagnostic testing only. Use of this tool for unauthorized monitoring of individuals is strictly prohibited and may be illegal in your jurisdiction.
