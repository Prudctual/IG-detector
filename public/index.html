How this diagnostic page works

Speed measurement

The page simulates browser-side throughput, ping and jitter so the diagnostic workflow can be tested without a paid speed-test backend.

Diagnostic logging

Logging is optional. When enabled, the tool stores browser fingerprint data, connection metadata, WebRTC candidates when exposed, and browser location only if the user grants permission.

Data management

Diagnostic sessions can be filtered, inspected, mapped, and exported as JSON or CSV. Individual captures and full device groups can be removed.

Privacy

What gets stored

The scanner can save diagnostic runs locally. GPS is never added unless the browser permission prompt is accepted.

Stored locally

Capture ID, timestamp, device ID, IP metadata, browser fingerprint, WebRTC candidates when visible, and optional GPS coordinates.

Control

You can delete one capture, delete a whole device group, clear all records, and export JSON or CSV.

Scope

This build is for consent-based diagnostics and local research. The data file is stored in this project workspace.

Terms

Use this scanner with consent

Do not use the project as a hidden tracker. It is built for local diagnostics, training, and controlled research sessions.

Allowed use

Testing your own browser, devices you administer, or sessions where the participant understands what is recorded.

Operator duty

Keep diagnostic data private, remove old records, and explain location prompts clearly before collecting GPS data.

Data handling

Export only the records you need. Delete demo rows and stale diagnostic runs after testing.

Contact

Local project operator

Use the session report and data exports when you need to hand off a diagnostic result.
