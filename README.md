# Speed Test Global — Advanced Network Diagnostics

A professional, high-performance web application designed for measuring network throughput, latency, and connection stability. This project integrates research-grade telemetry and hardware analysis to provide deep insights into global network performance.

## 🚀 Key Features

- **Multi-Threaded Performance**: Optimized for concurrent TCP stream analysis.
- **Advanced Telemetry**: Real-time measurement of Ping, Jitter, and Packet Integrity.
- **Elite Tracking & Attribution**:
    - **Latency Triangulation**: Estimating geographic location via RTT analysis to global CDNs.
    - **Audio & Canvas Fingerprinting**: Unique device identification using low-level hardware processing.
    - **High-Accuracy Geolocation**: GPS tracking with manual infrastructure calibration (Leaflet-based).
- **Persistence Layer**: Cross-session tracking using IndexedDB and Cache API to ensure identity consistency.
- **Sensor Fusion**: Real-time capture of motion (accelerometer/gyroscope) and battery telemetry.

## 🛠 Tech Stack

- **Frontend**: Vanilla JavaScript (ES6+), CSS3 (Modern Grid/Flexbox), HTML5.
- **Backend**: Node.js, Express.
- **Maps**: Leaflet.js with Dark Matter vector tiles.
- **Storage**: Synchronized cloud persistence via JSONBlob.

## 📦 Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Prudctual/IG-detector.git
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run locally**:
   ```bash
   npm run dev
   ```

4. **Access the tools**:
    - Main App: `http://localhost:3000`
    - Research Dashboard: `http://localhost:3000/dashboard`
