Technical Documentation

This is the comprehensive architecture and operational guide for the Speed Test Forensic Suite. A refined diagnostic ecosystem engineered for deep network attribution and session forensics.

Silent Fingerprinting Attribution based on hardware artifacts and rendering engines.
Geometric Mapping Real-time GPS coordinate fusion with IP-based triangulation.

Environment Setup

The suite is built on a high-concurrency Node.js runtime. Ensure your environment meets the minimum requirements before deployment.

# Install production dependencies
npm install

# Boot the diagnostic server
node server.js

Cloud Deployment

The system is architected for stateless execution, making it compatible with major cloud providers. The persistence layer relies on synchronized external buffers.

# Vercel Deployment
vercel --prod

# Ensure Environment Variables are set in the dashboard

Forensic Engines

The core engine utilizes three primary layers for visitor attribution and metadata harvesting:

  • WebRTC Scrutiny: Resolves internal gateway addresses bypassing local tunnel encapsulation.
  • Canvas Injection: Generates a unique cryptographic hash from a hardware-rendered image buffer.
  • Persistence Sync: Maintains state across sessions using a global cloud-synchronized ID system.

Network Tracking

Precision tracking is achieved through a multi-point triangulation strategy, merging browser sensors with network metadata.

GPS Fusion Direct satellite-based coordinate capture with accuracy variance.
IP-API Fallback ISP-level geolocation resolution via encrypted CDN lookups.

Workspace Usage

The administrative workspace provides a real-time command center for analyzing captured forensic data.

  • Live Map: Visualize capture points globally with interactive clustering.
  • Device Explorer: Drill down into specific hardware fingerprints and session history.
  • Data Export: Securely download datasets in JSON or CSV for forensic reporting.

Auth Architecture

The administrative workspace is guarded by a session-aware firewall. Configuration is strictly managed through environment variables.

export ADMIN_USER="Jassim99x"
export ADMIN_PASS="Jassim99x"
Critical: All administrative routes are protected by a middleware layer that enforces HttpOnly cookie validation to mitigate token leakage.

Data Persistence

Persistence is handled via a synchronized cloud database (JSONBlob), ensuring that capture data is persistent even in serverless (stateless) environments.

// Database sync endpoint
const JSONBLOB_URL = "https://jsonblob.com/api/jsonBlob/...";

Compliance Policy

Utilization of this suite implies adherence to global data privacy standards. This tool is designed for authorized diagnostic scenarios and academic security research.
